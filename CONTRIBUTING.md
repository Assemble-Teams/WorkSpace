# Contributing to WorkSpace

Thank you for helping us empower small R&D businesses in Defense, Space, Energy, and Transit. Every contribution matters.

## Ways to Contribute

### 🛠️ Engineering
- New AI employee agents
- Workflow integrations (SAM.gov, SBIR.gov, grants.gov)
- Frontend components and pages
- Backend API improvements

### 📐 Domain Templates
- SBIR/STTR proposal templates
- BAA response frameworks
- Capability statement formats
- University-industry teaming agreements
- Subcontractor coordination templates

### 🔬 Domain Knowledge
- Defense procurement expertise
- Space systems knowledge
- Clean energy R&D context
- Transit/mobility domain data

### 📖 Documentation
- User guides for non-technical founders
- Tutorial walkthroughs
- Translations

## Getting Started

1. Fork the repo
2. Create a branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Open a Pull Request

## Community Guidelines

- Be welcoming and respectful
- Remember our users are often overwhelmed founders — keep that empathy front and center
- Every PR should include context on how it helps small providers

## Questions?

Open a [GitHub Discussion](https://github.com/Assemble-Teams/WorkSpace/discussions) or file an issue.
